The Starry Road
The Starry Road is a text-based choose-your-own-adventure game written in Python. Explore a mysterious forest and village, collect items, and use them to unlock choices and discover different endings.

Requirements
Python 3
Colorama
Install Colorama with:

python -m pip install colorama
How to Run
From the project directory, run:

python adventure.py
Follow the numbered prompts to make choices. Enter y when asked to restart, or n to quit.

How I Used GitHub Copilot
I used GitHub Copilot to help build the game’s story and choice system, add inventory-based options, and include colored output and an intro banner.
